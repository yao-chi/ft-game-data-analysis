## 一、长版（约 480 字，适合直接粘贴）

**项目名称**：金铲铲之战 · 自走棋运营策略数据分析

**项目简介**：金铲铲之战的排位本质是"回合制经济决策 × 多元名次目标"的组合优化问题。我构建了一套覆盖"对抗模拟 → 回合级数据 → 运营策略归因"的完整数据分析管线：用 Python 实现经济引擎（基础收入 + 10% 利息 + 连胜奖励）、四种主流运营流派（存钱 / 速本 / 赌狗 / 均衡）的策略模拟器，生成 800 场对局、21.6 万条回合级数据；随后完成清洗、玩家级聚合（经济 / 人口 / 战力 / 连胜 / 淘汰节奏等指标），产出 9 张分析图表与结构化结论。

**核心发现**：① 均衡流平均名次 3.96、前四率 59.4%，是最稳的运营策略；存钱流吃鸡率最低，风险最高；② 利息从 0.9 提到 2.7 金/回合，平均名次仅从 4.69 升到 4.42——经济是"优化项"而非"胜负手"；③ 连胜 9 局以上玩家平均名次 1.50，滚雪球效应显著；④ 总投入（r=-0.88）与存活回合（r=-0.93）是名次的最强解释变量。

**我的职责**：指标设计（利息效率、人口节奏、连胜收益）、数据生成模型、全部清洗与聚合代码、自研 SVG 图表渲染器（零第三方依赖，不依赖 matplotlib）、报告撰写与结论提炼。

**与 AI 协作部分**：① AI 先根据我对金铲铲机制的口述（利息公式、流派打法）快速搭建模拟器骨架，我验证数值并修正经济模型（如利息收益封顶、野怪轮次收入）后定稿；② AI 与我共同排查数据失真——早期版本玩家名次与现实分布脱节，通过逐层定位到"存款目标驱动支出"逻辑并调参收敛；③ 我坚持让 AI 为每张图配"数据生成的一句话结论"，养成"用图表证据说话"的习惯，也方便面试时快速复盘。

**作品链接**：https://github.com/yao-chi/tft-game-data-analysis

## 二、短版（约 250 字）

**金铲铲之战 · 自走棋运营策略数据分析**：我构建了覆盖"模拟→清洗→分析→可视化"的完整数据管线。用 Python 实现含利息机制与四流派策略的对抗模拟器，生成 800 局 / 21.6 万条回合级数据，聚合出经济、人口、连胜、淘汰等维度，产出 9 张图表与结构化结论。核心发现：均衡流平均名次 3.96 全流派最优、存钱流风险最高；利息是优化项而非胜负手（0.9→2.7 金/回合仅改善 0.27 名）；连胜滚雪球显著（9+ 连胜平均 1.5 名）；总投入与存活回合是名次最强解释变量（r=-0.88 / -0.93）。全部图表由我自研的 SVG 渲染器绘制、零第三方图表依赖，seed=42 可复现。与 AI 协作方式：AI 依我口述的游戏机制生成模拟器骨架，我验证经济模型与调参；共同定位"玩家名次分布失真"问题至存款目标逻辑；并坚持每图配数据结论、用证据说话。

## 三、答辩要点（面试被追问时用）

| 可能被问 | 建议回答 |
|---|---|
| 数据是不是真的？ | 坦诚说明：官方不开放对局数据，数据按公开机制认知模拟生成，seed=42 可复现；项目价值在完整数据科学方法链（问题→指标→构造→聚合→归因→可落地结论），而非数据来源 |
| 金铲铲与现实机制差异？ | 简化了装备、羁绊、选秀等维度，聚焦经济与流派两大主干；正因抽象，结论更易被验证与复现 |
| 你的独立贡献在哪？ | 指标设计（利息效率、人口节奏）、数据生成模型、全部清洗聚合与渲染代码、结论提炼；AI 承担骨架搭建与排错建议 |
| 为什么不用 pandas 之外？ | 零第三方依赖是刻意的：自研 SVG 渲染器（bar/line/multi-line/heatmap），任何环境一条命令跑通，也展示图表系统实现能力 |
| 最有价值的一个发现？ | 反直觉结论：存钱流（高利息）平均成绩最差——"利息是优化项不是胜负手"，真正决定名次的是总投入与存活节奏；这教会我用数据证伪直觉 |
| 最难解决的 bug？ | 玩家名次分布与现实脱节：定位到"存款目标驱动支出"的回合误差累积，修正后四流派名次与表现分层收敛于合理区间 |
| 后续方向？ | 加入羁绊/装备系统提升机制保真度；用模拟器做策略寻优（经济曲线参数搜索）；对真实运营数据（如官方 API 允许的范围）做验证 |
